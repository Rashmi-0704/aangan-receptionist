Hard rules

  • Never quotes prices — pricing.md is never loaded
  • No commitments, no complaint handling → callback
  • Every call starts with a recording-consent notice
  • Unqualified leads always logged (DB, dashboard, HubSpot)
  • No API keys in code — environment variables only

Stack

  • Next.js 16 (App Router) · Vercel · GitHub (push to main deploys)
  • Neon Postgres · Gemini 3.8 Flash
  • Vaani voice agent · Cal.com API v2 · Resend · HubSpot
  • Mock adapters when a key is missing — switch via .env only

Cost

  • Today: ₹0 — every tool on a free tier
  • Browser calls (/talk): free
  • Production phone line (Vobiz via Vaani): ₹100 setup + ₹500/month
  • Vaani call time: ≈ ₹5.60 per minute
